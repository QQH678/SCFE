# SCFE：显著性-相关性特征增强

[English](README.md) | [简体中文](README.zh-CN.md)

本工作提出了一种面向小目标检测的特征增强检测框架。该框架以 YOLO11 为基础，引入了一种低参数量的显著性-相关性特征增强模块（Saliency-Correlation Feature Enhancement，SCFE），以有效增强网络对小目标的特征表征能力。具体而言，SCFE 构建了局部显著性路径和全局相关性路径，同时捕获特征图中的局部判别信息与长程依赖关系，从而提取并补偿微弱的目标信号。在局部路径中，采用无参数能量函数捕获目标的离群显著性；在全局路径中，利用外积运算建模像素间的拓扑相关性，并补充被稀释的结构信息。此外，引入低参数量的 BiLSTM，动态调节两类特征的融合比例，从而提升模型在不同目标密度条件下的鲁棒性。在特征聚合阶段，采用 DySample 动态上采样和 SPPCSPC 模块，以减少尺度变换过程中的细节损失，并进一步引入 EMA 模块，优化跨尺度上下文信息交互。最后，针对密集小目标场景，在模型架构中增加了一个高分辨率检测头 P2-Head，从而构建全尺度感知系统。
